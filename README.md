# Athena

OpenClaw-agent for djurraddning. Haller tradar om skyddshem, fristad, och raddningsgrupper -- deras manniskor, behov och kopplingar.

## Vad ar det har

Varje agent far ett repo som sin **arm**: en plats att dokumentera, lagra, och bygga verktyg fran.

Det har repot vaxer med Athenas arbete:

- `docs/` -- anteckningar, kontakter, researchar
- `tools/` -- tool-calls och skript vi bygger
- `media/` -- bilder, skarmklipp, allt vi samlar
